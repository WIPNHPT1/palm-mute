Tighten the home page's moving background

The Song Generator and the Chord Lab have one oscilloscope fixed behind the whole window: one grid, waves sized to the window, drawn at the 90% design scale. The home page instead draws a separate scope inside each quiet section (intro, two notes, title board, encore), sized to that section. So the waves are a different size in every section, the grid restarts at each one, and each section fades out at its edges. Today's version and the Generator are first, for comparison. Each preview is a 1440px window shrunk to fit; scroll inside it.

WHAT CHANGES
The four per-section scopes become the same single fixed scope the Generator and Chord Lab use. Same grid, same wave sizes, same 90% scale. The quiet sections are windows onto it. The hero, the setlist and the stamp band keep their own solid backgrounds, so the scope only shows where it shows today.
HOW IT FEELS
Moving between pages, the background is literally the same thing. Scrolling the home page, the grid stays put and the content glides over it, as on the Generator. Sections meet the scope with a clean edge.
COST
Less than today: one canvas instead of four. It reuses StageBackground, so Scope.tsx goes away.

WHAT CHANGES
The same single fixed scope as A. Where a quiet section meets a solid one (the hero, the setlist, the band), the scope fades in and out over the same distance as today's fades.
HOW IT FEELS
It matches the other pages, and the home page keeps its gentler hand-offs between sections. It's softer than A, so it reads a little less like one continuous surface.
COST
Same as A, plus two fade strips per quiet section. Gradients only, no masks on the canvas.

WHAT CHANGES
The same single fixed scope, but on the home page the traces stay hidden until the encore ("Count it in."), where they fade in. The quiet sections above it show just the still grid.
HOW IT FEELS
Calmer reading through the page. The traces arriving at the end feel like the music starting, which suits the 1-2-3-4 count-in that's already there.
COST
Same as A. Most of the page is a still frame, so it's cheaper while scrolling.
